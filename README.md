# Розклад 5-Б

Показує, який зараз урок, скільки до перерви і що далі, з урахуванням
чергування синього та жовтого тижнів.

**Додаток:** https://oleksiikonanchyk.github.io/rozklad/

## Як оновити розклад

Уся інформація живе в одному файлі — [`schedule.json`](./schedule.json).
Його можна редагувати прямо на github.com, зокрема з телефона: відкрити
файл → олівець → правки → Commit. За пів хвилини зміни вже в додатку.

### Новий розклад після канікул

Не перезаписувати наявний. Додати другий запис у масив `schedules`:

```json
{
  "validFrom": "2027-01-11",
  "anchor": { "weekStart": "2027-01-11", "color": "yellow" },
  "weeks": { "yellow": { }, "blue": { } }
}
```

`validFrom` — перший навчальний день нового розкладу. `anchor` — будь-який
понеділок і його колір. Додаток сам перемкнеться в потрібну дату, тож новий
розклад можна закомітити заздалегідь.

### Якщо школа зіб'є чергування тижнів

Дописати потрібний понеділок у `weekOverrides`:

```json
"weekOverrides": { "2026-11-02": "blue" }
```

Цей тиждень стане синім, решта рахуватиметься формулою далі.


`src/`, покриті тестами; `src/ui.js` тільки малює готовий стан.
