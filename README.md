# Розклад 5-Б

Показує, який зараз урок, скільки до перерви і що далі, з урахуванням
чергування синього та жовтого тижнів.

**Додаток:** https://oleksiikonanchyk.github.io/rozklad/

## Як оновити розклад

Уся інформація живе в одному файлі — [`schedule.json`](./schedule.json).
Його можна редагувати прямо на github.com, зокрема з телефона: відкрити
файл → олівець → правки → Commit. За пів хвилини зміни вже в додатку.

### Новий розклад після канікул

Не перезаписувати наявний. Додати другий запис у масив `schedules`:

```json
{
  "validFrom": "2027-01-11",
  "anchor": { "weekStart": "2027-01-11", "color": "yellow" },
  "weeks": { "yellow": { }, "blue": { } }
}
```

`validFrom` — понеділок того тижня, коли починається новий розклад (навіть
якщо перший навчальний день — не понеділок). `anchor` — будь-який понеділок
і його колір. Додаток сам перемкнеться в потрібну дату, тож новий розклад
можна закомітити заздалегідь.

### Коли вчитель ще не відомий

Буває, що урок у розкладі вже є, а хто його веде — ще не сказали. Тоді
залишають порожній список:

```json
"2": { "subject": "Еврика", "teachers": [] }
```

Додаток напише «вчитель і кабінет уточнюються» замість кабінету. Щойно
стане відомо — допишіть учителя, і напис зникне сам.

### Значки предметів

Перед назвою кожного предмета стоїть емодзі — його беруть із `subjectIcons`:

```json
"subjectIcons": {
  "Математика": "🔢",
  "Англійська мова": "🇬🇧"
}
```

Ключ має точно збігатися з назвою предмета в розкладі. Предмет, якого немає
в цьому списку, отримає 📘 — тож новий предмет нічого не зламає, просто
додайте йому рядок, коли захочете.

### Якщо школа зіб'є чергування тижнів

Дописати потрібний понеділок у `weekOverrides`:

```json
"weekOverrides": { "2026-11-02": "blue" }
```

Цей тиждень стане синім, решта рахуватиметься формулою далі.

## Розробка

```bash
npm install
npm test          # Vitest
python3 -m http.server 8000   # відкрити http://localhost:8000/
```

Збірки немає: GitHub Pages віддає файли як є. Логіка — чисті функції в
`src/`, покриті тестами; `src/ui.js` тільки малює готовий стан.
